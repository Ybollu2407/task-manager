# 🚀 Task Manager Pro

A simple yet powerful task management web app where admins can assign tasks and users can track and complete them.

---

## 🧠 About the Project

This project is built to solve a common problem — managing tasks within a team. Instead of using complex tools, this app keeps things clean and focused.

* Admin can create and assign tasks
* Members can view and update their assigned tasks
* Authentication ensures secure access
* Clean UI with a smooth user experience

---

## ⚙️ Tech Stack

**Frontend**

* React (Create React App)
* CSS (Custom styling with modern UI)

**Backend**

* Node.js
* Express.js

**Database**

* MongoDB Atlas

**Authentication**

* JWT (JSON Web Tokens)

**Deployment**

* Frontend: Vercel
* Backend: Render

---

## 🔐 Features

* User Signup & Login
* Role-based access (Admin / Member)
* Admin can:

  * Create tasks
  * Assign tasks to users
* Members can:

  * View their tasks
  * Mark tasks as completed
* Task filtering (Pending / Completed)
* Search functionality
* Responsive and clean UI

## 🚀 How to Run Locally

### 1. Clone the repo

```
git clone https://github.com/your-username/task-manager.git
```

### 2. Backend setup

```
cd backend
npm install
npm start
```

### 3. Frontend setup

```
cd frontend
npm install
npm start
```
